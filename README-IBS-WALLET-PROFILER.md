# IBS 卖家地址画像（独立工作流）

监控范围仅限官方 IBS/USDT 池。每笔卖出同时保留交易发起地址、IBS直接入池地址和USDT直接接收地址，避免把Router或聚合器路径简单当作最终身份。

地址行为分类包括：平台/协议地址、协议来源IBS变现、团队长/归集地址疑似、外部转入变现、短周期盈利交易、高频交易、普通交易和未知成本卖出。团队长判断只有在至少5个外部地址向同一卖方归集IBS、该地址至少卖出3次且卖出量超过本池买入量时才触发，并始终标记为“疑似”。

默认单笔从LP取走至少5,000 USDT会立即进入异常通知；其他地址仅在异常条件首次出现、升级、累计卖出明显增加或定期复查时通知。

`IBS Seller Wallet Profiler` 每 5 分钟独立扫描官方 IBS/USDT LP。单笔卖出严格超过 20 IBS 时，对该笔交易的 `tx.from` 地址建立或更新完整画像；只有满足大额、持续变现、高频净流出或其他异常条件时才发送 Telegram。

核心指标：

- 最早可见 IBS 活动、买入、向 Staking 转入的时间，以及平均已匹配持仓时间
- 全历史买卖次数、累计 IBS 和 USDT、平均买入成本
- 当前钱包余额、质押净转入估算、外部及协议地址转入转出
- 触发卖单占当前 LP 的 IBS/USDT 储备比例
- 已实现盈亏与按当前池价计算的总盈亏估算，并明确标注可信度
- 地址类型：平台/协议、合约/聚合器、高频套利、普通地址、关联风险待观察、关联/老鼠仓高疑似

重要边界：分类是链上行为标签，不是身份或违法定性。盈亏只覆盖官方 IBS/USDT LP；其他池、中心化交易所、场外交易、手续费、质押奖励和无法识别的转账会降低可信度。智能钱包、路由或聚合器的 `tx.from` 也可能不是最终受益人。

状态单独保存在 `data/ibs_wallet_profiles.json`，不读取或修改核心资金监控状态。首次启用仅建立当前区块基线，不补发全部历史卖单。
